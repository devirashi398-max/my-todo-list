# My To-Do List

This is a simple To-Do List project I built while learning web development.

### Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Add tasks by pressing Enter
- Save tasks even after refreshing the page
- Works on mobile and desktop

### Built With
- HTML
- CSS
- JavaScript

### How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start adding your tasks!

### What I Learned
While building this project, I practised JavaScript events, DOM manipulation, CSS styling, and LocalStorage.

This is one of my practice projects as I continue learning web development.
